# 关爱女性健康|鱼台县总医院西院区（县妇幼保健院）“两癌”筛查，给健康一份“定心丸”

> 更新时间：2026-09-16 (UTC+8)

**什么是“两癌”**      两癌”是指威胁女性健康的乳腺癌和宫颈癌。我国每年新发宫颈癌约13万例，乳腺癌更是位居女性恶性肿瘤发病首位，且发病年龄逐渐年轻化。什么是“两癌”筛查?“两癌”筛查:是指通过先进的检查手段，从正常人群中发现癌症患者或可疑癌症患者。“两癌”筛查的目的:将这两种癌症，尽早的筛查出来，做到早发现、早诊断和早治疗。 **宫颈癌高危人群**1、常见于40-60岁女性。2、人乳头瘤病毒(HPV)感染者。3、有宫颈癌家族史者。4、有多个性伴侣者(>3个)。5、性生活时间开始过早(<16岁)。6、吸烟者。7、长期无保护性行为。8、长期口服避孕药者。 **如何预防宫颈癌**      1、接种HPV疫苗。      2、进行宫颈癌筛查。      3、细胞学检查:液基薄层脱落细胞学检查法。      4、HPV检测:是宫颈癌的有效检查方法。

 **宫颈癌检查方法**      1、宫颈细胞学检查:宫颈细胞学检查为宫颈痛检查的首选，可以有效反映受检时的宫颈的健康状况。目前，最常用的检测方法为液基薄层细胞学(TCT)检测系统，检测宫颈细胞并进行TRs细胞学分类诊断，是目前国际上较先进的一种宫颈癌细胞学检查技术。TCT能检出70%以上的病瘤和癌前病变，同时还能发现微生物感染如霉菌、滴虫、病毒等。
      2、阴道镜检查:对妇科检查发现宫颈异常改变或触血、宫颈脱落细胞检查结果可疑者或异常者以及肉眼检查异常者进行阴道镜检查。
**我需要检查吗**     ( 宫颈癌)2016年美国妇产科医师协会( ACOG )推荐筛查意见要点:      1、21岁以下女性:无需筛查。      2、21 -29岁女性:每3年进行细胞学检查。      3、30-65岁女性:每5年进行细胞学检查和HPV DNA联合检查(推荐)或每3年一次细胞学检查(可选)。      4、65岁以上女性:既往多次筛查为阴性则无需筛查。      5、接种HPV疫苗的女性:依照各年龄段的建议(与未接种疫苗的女性相同)。

      **乳腺癌高危人群**

      1、常见于30 -70岁女性。

      2、有乳腺癌家族史者。

      3、有乳腺良性疾病者。

      4、月经来的早(<12岁)，绝经迟(大于55岁)。

      5、高龄未婚、婚后未育、生育后未哺乳者。

      6、胸部接受过高剂量放射线照射。

      7、吸烟、过量饮酒者。

      8、长期口服避孕药者。

      **如何预防乳腺癌**      1、乳腺超声检查: 经济、安全、无痛苦的乳腺检查方法，适合于年轻女性，尤其是妊娠期哺乳期的妇女更为适宜。      2、乳腺X线照相检查(钼靶照相) :是乳腺癌筛查中主要的检查方法，能帮助医生发现触及不到的病灶。      **我需要检查吗**    ( 乳腺癌)中国抗癌协会乳腺癌诊治指南与规范( 2015版)推荐筛查要点:该指南对于非高危人群建议:      1、40-49岁的女性:每年1次乳腺X线照相检查。      2、50-69岁女性:每1-2年 进行1次乳腺X线照相检查。      3、≥70岁的女性:每2年进行1次乳腺X线照相检查。      4、对于上述人群均推荐结合临床乳房检查，对于致密型乳腺推荐进行乳腺B超联合检查。      5、高危人群建议提前进行检查(< 40岁)，筛查频率推荐每半年1次，筛查手段除了采用正常人群的临床乳房体检、B超、乳腺X线照相检查之外，可采用MIR等新的影像学手段。
      **乳腺钼靶检查**      乳腺钼钯检查系统是一种低剂量乳腺X光拍摄乳房的技术，它能清晰显示乳腺各层组织，可以发现乳腺增生，各种良恶性肿瘤以及乳腺组织结构紊乱，可观察到小于0.1毫米的微小钙化点及钙化簇，是目前早期发现，诊断乳腺癌的最有效和可靠的方式，尤其对于临床不可能及的，以微小钙化簇为唯一表现的早期乳腺癌具有特征性的诊断意义。对于彩超无法辨别的乳腺病变钙化点进行准确判断与鉴别，是乳腺彩超检查的必要补充。

      **适应症**      1、发现有乳房肿块或结节者。      2、排除了垂体病变的乳头溢液者。      3、乳腺癌高危人群和40岁以上女性的普查。      4、一侧乳腺癌手术后随访对侧乳腺。      5、曾作隆胸手术，疑植入的假体有异常者。      6、对乳腺超声检查BI-RADS分级0级以及3级以上者。
