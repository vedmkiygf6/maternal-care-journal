# 青舞飞扬、志愿你我— —山东第一医科大学附属济南妇幼保健院门诊首期暑期青少年志愿者招募令

> 更新时间：2026-09-11 (UTC+8)

**招募令**
“青春正当时，吾辈当自强”，为弘扬新时代志愿服务精神，让更多有爱心、乐于奉献的志愿者走进妇幼，走近医务工作者，山东第一医科大学附属济南妇幼保健院为青年学子提供了社会实践平台，现面向各大院校在校学生招募志愿者。希望广大青少年积极助力妇幼卫生健康志愿事业，用实际行动奉献青春力量，充分展现新时代青年的奋斗底色和责任担当。欢迎有志于自愿提供爱心服务的学子们踊跃报名参与。

**活动时间**

2023年7月10日-8月18日****

**活动安排**

**活动地点**

山东第一医科大学附属济南妇幼保健院门诊楼

**招募条件**

1. 初、高、大学等各大院校在校青少年。
2. 身体健康，热心公益事业，具备高度的责任心和服务意识，具有良好的心理素质及人际沟通能力，能够保证相对固定的服务时间，组织纪律强，服从统一指挥、调度和管理。

3. 经培训后按统一安排具体岗位及工作时间。

活动内容

志愿者队伍由医院门诊部、团委统一进行管理。

**（一）志愿岗位**

1. **就医引导志愿岗**

协助患者分流，维持现场秩序，引导患者有序挂号、检查、就医 、线上智能应用、便民服务等；了解医院门诊运行，志愿服务的岗位职责。

2. **科室服务志愿岗**

协助门诊医护人员做好科室内患者服务及科室相关物资管理、数据统计、健康宣教等；

3. **特色服务志愿岗**

**（二）服务时间**

周一至周五全天（08:00-16:00，包含午餐及午休时间）

**（三）服务地点**

1. 山东第一医科大学附属济南妇幼保健院（市中区建国小经三路2号）

2. 山东第一医科大学附属济南妇幼保健院西院区（市中区经七纬一476号）

**（四）报名方式及服务保障**

**报名方式**

1. 现场报名（报名者需持身份证和一寸免冠彩照一张，填写志愿者登记表）

市中区胜利大街34号106室，门诊部办公室。

2. 电话报名

联系人：杨老师 、牛老师

联系电话 0531-89029312

3. 扫描二维码线上填写报名表（线上报名截止日期2023年7月6日）

4. 资格确认

门诊部采集志愿者相关身份信息，依据基本条件范围内的条款进行面试并予以上岗前培训，培训合格者即可成为本院志愿者，参与各项志愿服务。

5. 招募人数：每期15人，报满即止

**志愿服务保障**

1. 为志愿者提供志愿者相关防护用品、志愿者服装、志愿者时长证明，为符合条件的志愿者颁发优秀证书、出具社会实践证明及表扬信。

2. 服务期间，志愿者可免费参与门诊部、团委及医院相关培训及交流课程，享受医院提供工作午餐及午休等。

3. 门诊部、团委联合组织召开志愿者座谈会，交流收获的喜悦及奉献的初衷，并在会上颁发证书。

4. 优秀志愿者优先参与医院公布的志愿者服务需求，如重大节日、社区义诊、大型活动保障及环境整治等。

****
